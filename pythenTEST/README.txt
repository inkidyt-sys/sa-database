DSA Helper (石器時代輔助程式 v5.x)
這是一個專為「石器時代」(DSA 新端 / sadsa.exe) 開發的 Python 外部輔助工具。
本程式採用多執行緒架構讀取遊戲記憶體，提供實時的角色與寵物數據監控，並整合了常用的遊戲功能修改（如加速、穿牆等）。

【更新於 2025年12月】
- v5.0 UI 完全重構，支援戰鬥實時監控與血條顯示
- 增加石幣、回合數實時監控
- 改進記憶體管理與自動重連機制
- 優化DPI縮放計算，修正像素字體顯示

核心功能 (Features)

1. 多客戶端管理
✓ 支援同時綁定與監控最多 6 個遊戲視窗
✓ 自動偵測並列出可綁定的遊戲進程 (PID)  
✓ 自動偵測遊戲離線並重置狀態
✓ 支援個別視窗的隱藏/顯示、縮小/還原操作（透過右鍵點擊）

2. 實時數據儀表板 (Dashboard)
人物資料：即時顯示 LV、轉生次數、HP/MP、攻防敏、四屬性（地水火風）、詳細三圍、以及石幣

寵物監控：
✓ 支援顯示 5 隻攜帶寵物的詳細數值
✓ 顯示成長數據（LV, EXP, 欠缺經驗）
✓ 狀態顯示：整合寵物當前狀態（戰鬥、騎乘、郵件、等待、休息），並以對應顏色區分
✓ 忠誠度監控：低於 20% 時顯示紅色警告

3. 戰鬥實時監控 (NEW in v5.0)
✓ 即時顯示雙方陣容（最多5人/隊）
✓ 人物與騎寵血條動態顯示
✓ 顯示等級 [LV] 與當前/最大 HP
✓ 回合計數與指令目標高亮
✓ 死亡狀態顯示（紅色提示）

4. 遊戲功能修改 (Memory Patching)
透過修改記憶體特徵碼 (AOB) 實現以下功能：
✓ 遊戲加速：調整遊戲邏輯速度
✓ 快速行走：移除移動延遲
✓ 穿牆行走 (No Clip)：允許角色穿越障礙物
✓ 隱藏視窗：利用 WinAPI 隱藏遊戲視窗以節省資源

5. 高度最佳化的 UI 體驗
DPI 感知與解析度適配：
✓ 自動偵測 Windows DPI 縮放 (100%, 125%, 150%)
✓ 動態計算所有 UI 元素大小、間距與字體
✓ 支援手動縮放 75% ~ 150% 調整
✓ 自動高度調整模式

效能優化：
✓ 採用精確更新 (Granular Update) 機制
✓ 僅重繪數值發生變動的 UI 項目
✓ 記憶體讀取與 UI 渲染分離（Producer-Consumer 模式）
✓ 可調整刷新率（0.5s ~ 60s）以平衡效能

專案結構 (File Structure)

| 檔案名稱 | 用途描述 |
|---------|--------|
| main.py | 程式入口點。視窗管理、執行緒協調、DPI 偵測、數據更新與 UI 控制 |
| app_ui.py | UI 佈局核心。Tkinter 元件、Canvas 繪圖、DPI/解析度縮放計算 |
| memory_worker.py | 後台執行緒。使用 pymem 讀取遊戲記憶體、解析指針結構，將數據打包傳送 |
| game_scanner.py | 記憶體掃描。尋找遊戲視窗、AOB 特徵掃描、記憶體地址定位 |
| game_features.py | 功能控制。執行記憶體修改與功能開關邏輯 |
| constants.py | 常數定義。記憶體偏移量、AOB 特徵碼、顏色表、客戶端設定 |
| ui_components.py | UI 元件庫。可捲動框架等自定義 Tkinter 元件 |
| utils.py | 工具函式。權限檢查、Big5 解碼、數值格式化等 |

系統需求 (Requirements)

- Windows 7 或更新版本
- Python 3.8+
- 必要套件：
  ✓ tkinter（通常內建）
  ✓ pymem（記憶體讀寫）
  ✓ psutil（進程管理）
  ✓ ctypes（Windows API）

安裝與使用 (Installation & Usage)

1. 安裝依賴：
   pip install pymem psutil

2. 以管理員身份運行：
   python main.py

3. 操作步驟：
   - 點擊「綁定石器」自動掃描並綁定遊戲視窗
   - 勾選要監控的窗口，查看「人寵資料」、「道具列表」、「戰鬥狀態」
   - 在「遊戲設置」頁籤啟用各項功能（加速、穿牆等）
   - 右鍵單擊窗口列表可縮小，雙擊可還原

進階設定 (Advanced Configuration)

刷新率調整：
  0.5s ~ 3s：即時反應，高 CPU 佔用（適合手動操作）
  5s ~ 10s：平衡模式（推薦掛機使用）
  60s / 不刷新：低耗能模式（適合監控用）

UI 縮放：
  支援 75% ~ 150% 的手動縮放
  自動 DPI 感知，會根據系統設定自動調整基礎縮放

自動高度：
  啟用時，視窗高度會根據內容自動調整
  禁用時，可手動調整視窗大小

常見問題 (Troubleshooting)

Q: 「錯誤：請以管理員身份執行」
A: 右鍵選擇「以管理員身份執行」或在命令提示字元用 runas 執行

Q: 記憶體偏移量不符
A: 遊戲版本更新時需更新 constants.py 中的偏移量，可使用 Cheat Engine 重新掃描定位

Q: UI 顯示異常、字體過大/過小
A: 嘗試調整「UI縮放」選項，或在 app_ui.py 手動修改 LAYOUT_PARAMS

Q: 無法綁定遊戲視窗
A: 確認遊戲已啟動且視窗可見，檢查遊戲進程名稱是否為 sadsa.exe

注意事項 (Important Notes)

⚠️ 本程式需要管理員權限以進行記憶體讀寫操作

⚠️ 本程式依賴特定的記憶體位址與特徵碼 (constants.py)，若遊戲版本更新，可能需要重新掃描

⚠️ 遊戲視窗關閉時，程式會自動重置綁定狀態，避免記憶體泄漏

⚠️ 長時間運行建議定期重啟程式，以優化記憶體占用

開發與改進 (Development)

本專案採用模組化架構，便於擴展：
- 新增功能：在 game_features.py 中實現，constants.py 中定義 AOB 特徵
- 新增 UI：在 app_ui.py 中定義繪製函式，使用 Canvas 或 Tkinter 元件
- 新增記憶體讀取：在 memory_worker.py 中擴展 _read_* 函式
