【改進 1】實現 AOB 快取機制 ✅
──────────────────────────────────
位置：game_scanner.py

功能：
  ✓ 自動保存 AOB 掃描結果到 aob_cache.json
  ✓ 下次啟動時直接從快取讀取，無需重新掃描
  ✓ 支援快取失效時自動重新掃描
  ✓ 記錄快取時間戳用於版本管理

效能提升：
  • 啟動時間：縮短 ~3-5 秒
  • AOB 掃描次數：從 N 次 → 1 次（第一次啟動）
  • 後續啟動：直接使用快取（0 次掃描）

實現方式：
  - load_aob_cache()：加載快取
  - save_aob_cache()：保存快取
  - _scan_pattern()：快取查詢 → 掃描 → 保存
  - _scan_speed()：同上

【改進 2】添加配置管理 UI ✅
──────────────────────────────────
位置：main.py, config.py

功能：
  ✓ 自動載入配置預設值到 UI
  ✓ 修改 UI 設定時自動保存到 config.json
  ✓ 重啟程式時自動恢復設定

新增設定項目：
  • ui.default_refresh_rate (預設: "3s")
  • ui.default_zoom (預設: "100%")
  • ui.auto_height_enabled (預設: true)

實現：
  - on_refresh_rate_change()：刷新率變更 → config 保存
  - on_zoom_change()：縮放變更 → config 保存
  - __init__()：啟動時從 config 讀取預設值

【改進 3】記憶體讀取超時控制 ✅
──────────────────────────────────
位置：memory_worker.py

功能：
  ✓ 防止卡死的遊戲進程導致程式無回應
  ✓ 可配置的超時時間
  ✓ 超時時記錄警告日誌

實現方式：
  - with_timeout() 裝飾器：為函式添加超時
  - 使用 threading.Thread + join(timeout) 實現
  - 超時後返回 None，程式繼續執行

配置項：
  memory.aob_scan_timeout (預設: 10.0 秒)

安全性：
  • 不會傳播異常
  • 超時時安全退出子執行緒
  • 完整記錄警告日誌

【改進 4】異常警告 UI 面板 ✅
──────────────────────────────────
位置：app_ui.py, main.py

功能：
  ✓ 在主視窗頂部顯示即時警告訊息
  ✓ 顏色分級：紅色(ERROR) / 橙色(WARNING) / 藍色(INFO)
  ✓ 訊息自動淡出（5 秒後清除）
  ✓ 用戶無需查看日誌檔案即可知曉問題

元件位置：
  • 主視窗最上方（在 Notebook 之前）
  • 視覺上易於注意

新增方法：
  - add_warning(message, level)：添加警告訊息
  - _update_warning_display()：更新顯示

使用示例：
  app.add_warning("無法連接遊戲進程", "ERROR")
  app.add_warning("AOB 掃描失敗，使用快取", "WARNING")

【改進 5】效能監控面板 ✅
──────────────────────────────────
位置：performance_monitor.py, app_ui.py, main.py

新增頁籤：「效能監控」
顯示指標：

  1. 運行時間
     格式: X h Y m Z s
     
  2. 讀取統計
     • 成功次數
     • 失敗次數
     • 成功率計算
     
  3. 平均延遲
     格式: XX.XX ms
     • 計算：總耗時 / 成功次數
     
  4. CPU 使用率
     格式: XX.X %
     • 實時更新
     • 針對整個程式進程
     
  5. 記憶體使用量
     格式: XXX.X MB (峰值: XXX.X MB)
     • 當前記憶體
     • 自程式啟動後的峰值

實現：
  - PerformanceMonitor 類：核心監控邏輯
  - record_read()：記錄讀取操作
  - update_metrics()：更新系統指標
  - format_stats()：格式化輸出
  - update_performance_tab()：UI 更新（500ms 週期）

數據來源：
  • psutil.Process()：CPU 和記憶體
  • threading 計時：讀取延遲
  • 手動計數：讀取次數和失敗次數

【使用指南】

【AOB 快取】
  • 自動生成：aob_cache.json
  • 手動清除：刪除 aob_cache.json 重新掃描
  • 版本更新：遊戲更新後刪除快取

【配置管理】
  • 自動保存：修改 UI 設定時自動保存
  • 手動編輯：直接編輯 config.json
  • 預設值：首次啟動自動生成

【超時控制】
  • 調整超時：編輯 config.json

      "aob_scan_timeout": 10.0
    }

【異常警告】

  • 顏色參考：紅 = 嚴重, 橙 = 警告

【效能監控】
  • 查看位置：「效能監控」頁籤
  • 更新頻率：每 500 ms
  • 峰值記憶體：自程式啟動後的最大值
