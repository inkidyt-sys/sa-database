【快速開始】DSA Helper v5.0 安裝與使用指南

═══════════════════════════════════════════════════════════

STEP 1：環境準備

□ Windows 7 或更新版本
□ Python 3.8+ 已安裝
  驗證：在命令提示字元輸入 python --version

□ 管理員權限
  以管理員身份執行命令提示字元

═══════════════════════════════════════════════════════════

STEP 2：安裝依賴

在命令提示字元執行：

  pip install pymem psutil

等待安裝完成，應看到「Successfully installed」

═══════════════════════════════════════════════════════════

STEP 3：啟動程式

方法 A（推薦）：直接執行
  右鍵選擇 main.py，點擊「以管理員身份執行」

方法 B：命令列執行
  cd 到程式目錄，執行：python main.py

═══════════════════════════════════════════════════════════

STEP 4：基本操作

1. 綁定遊戲
   □ 點擊左側「綁定石器」按鈕
   □ 程式會自動掃描並綁定正在運行的石器時代視窗
   □ 勾選要監控的視窗

2. 監控數據
   □ 切換到「人寵資料」標籤
   □ 實時看到角色與寵物資訊
   □ 「道具列表」標籤查看背包
   □ 「戰鬥狀態」標籤在戰鬥時查看陣容

3. 啟用功能
   □ 切換到「遊戲設置」標籤
   □ 勾選「遊戲加速」、「快速行走」、「穿牆行走」
   □ 即時修改生效

═══════════════════════════════════════════════════════════

STEP 5：進階設定

【刷新率調整】
  應用程式 → 遊戲設置 標籤
  - 0.5s ~ 1s：高實時性（CPU 高）
  - 3s ~ 5s：平衡模式（推薦）
  - 10s ~ 60s：低耗能（CPU 低）

【UI 縮放】
  應用程式 → 遊戲設置 標籤
  - 75% / 100% / 125% / 150%
  - 自動適配系統 DPI

【自動高度】
  勾選後視窗自動調整高度以適應內容

【設定檔管理】
  編輯 dsa_helper_config.json
  - UI 預設值
  - 記憶體掃描超時
  - 日誌等級

═══════════════════════════════════════════════════════════

STEP 6：查看日誌

所有日誌存放在 ./logs/ 目錄

查看實時日誌：
  Windows PowerShell：
    Get-Content -Path logs\dsa_helper_*.log -Wait -Tail 20

檢查特定錯誤：
  notepad logs\dsa_helper_YYYYMMDD.log

日誌參考：
  [INFO]    - 正常操作信息
  [WARNING] - 可恢復的錯誤
  [ERROR]   - 需要注意的問題

═══════════════════════════════════════════════════════════

STEP 7：常見問題排查

【無法綁定視窗】
  ✓ 確認石器時代已啟動
  ✓ 遊戲視窗應在前台（可見）
  ✓ 檢查程式是否以管理員身份運行
  ✓ 查看日誌中是否有「Module not found」

【功能無法啟用】
  ✓ 確認視窗已「已綁定」狀態
  ✓ 遊戲版本可能更新，需重新定位 AOB
  ✓ 查看日誌中的「Scan failed」或「Address not found」

【UI 顯示異常】
  ✓ 試試改變「UI 縮放」設定
  ✓ 調整「自動高度」開關
  ✓ 拖拽視窗邊界手動調整大小
  ✓ 查看 config.json 中的字體設定

【記憶體佔用過高】
  ✓ 檢查綁定的視窗數量（最多 6 個）
  ✓ 降低刷新率（改為 10s）
  ✓ 查看是否有進程泄漏（查看日誌）
  ✓ 重啟程式

═══════════════════════════════════════════════════════════

STEP 8：功能詳解

【遊戲加速】
  - 加快遊戲邏輯速度
  - 適用於：掛機、刷副本
  - 風險：可能被偵測

【快速行走】
  - 移除移動動畫延遲
  - 適用於：快速移動
  - 效果：明顯加快移動速度

【穿牆行走】
  - 允許穿越地形障礙
  - 適用於：探索、收集
  - 風險：可能掉出地圖

【隱藏視窗】
  - 隱藏遊戲視窗
  - 適用於：掛機、節省資源
  - 操作：右鍵點擊窗口列表（縮小/還原）

═══════════════════════════════════════════════════════════

STEP 9：多視窗管理

支援同時監控最多 6 個石器時代視窗

操作步驟：
  1. 啟動多個石器時代客戶端
  2. 點擊「綁定石器」
  3. 程式會自動偵測並綁定所有視窗
  4. 左側勾選要監控的視窗
  5. 設置獨立應用於各視窗

左鍵操作：
  □ 勾選/取消勾選視窗

右鍵操作：
  單擊：最小化視窗
  雙擊：還原視窗

STEP 10：安全建議

⚠️  請注意
  1. 本工具需要管理員權限才能運作
  2. 修改遊戲記憶體可能被遊戲檢測
  3. 在不確定時勿啟用功能修改
  4. 建議先在低等級角色測試
  5. 保持程式和遊戲版本同步

最佳實踐：
  ✓ 定期檢查日誌以發現異常
  ✓ 使用中等刷新率（3-5s）平衡效能
  ✓ 當需要時才啟用功能修改
  ✓ 定期重啟程式清理內存
